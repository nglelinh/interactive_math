📊 Arrays & Dynamic Arrays

🎯 Arrays - The Foundation of Data Structures

Arrays are the most fundamental data structure - a collection of elements stored in contiguous memory locations, accessed by index.

🏆 Key Properties:

  • 🎯 Random Access: O(1) access time to any element
  • 📍 Index-based: Elements accessed via numerical indices
  • 🗂️ Homogeneous: All elements of same data type
  • 💾 Contiguous Memory: Elements stored next to each other

🏗️ Real-world Applications

  • 📊 Data Processing: Storing and processing datasets
  • 🎮 Game Development: Player inventories, game boards
  • 🖼️ Image Processing: Pixel data representation
  • 📈 Algorithms: Foundation for sorting, searching
  • 💻 System Programming: Buffers, caches

🔄 Array vs Other Structures

  • ✅ Pros: Fast access, memory efficient, cache-friendly
  • ❌ Cons: Fixed size (static), expensive insertions/deletions
  • 🆚 vs Linked Lists: Better access time, worse insertion
  • 🆚 vs Hash Tables: Ordered, predictable memory layout

📏 Static Arrays

Static Arrays have fixed size determined at compile time. Size cannot change during runtime.

// C++ Static Array Declaration int arr[5] = {10, 25, 7, 42, 13}; // Memory layout: // [10][25][7][42][13] // ↑ ↑ ↑ ↑ ↑ // 0x1000 0x1004 0x1008 0x100C 0x1010

🔍 Memory Calculation

For array arr[i], memory address is:

Address = base_address + (i × element_size)

Example: arr[3] = 0x1000 + (3 × 4) = 0x100C

⚙️ Basic Operations

📖 Access/Read

Time: $\O(1)$ - Constant

Why: Direct calculation using index

value = arr[index];

✏️ Update/Write

Time: $\O(1)$ - Constant

Why: Direct access to memory location

arr[index] = new_value;

🔍 Search

Time: $\O(n)$ - Linear

Why: Must check each element

for(int i = 0; i < n; i++) { if(arr[i] == target) return i; }

➕ Insert/Delete

Time: $\O(n)$ - Linear

Why: Need to shift elements

Note: Size is fixed!

📈 Dynamic Arrays

Dynamic Arrays can grow and shrink during runtime. Examples: C++ vector, Java ArrayList, Python list.

🔄 Resizing Strategy

When array is full and needs to grow:

  1. 🆕 Allocate: New array with 2× capacity
  2. 📋 Copy: All elements to new array
  3. 🗑️ Delete: Old array
  4. 🔗 Update: Pointer to new array

➕ Append (push_back)

Amortized: $\O(1)$

Worst case: $\O(n)$ (when resizing)

Average: Constant due to doubling strategy

➖ Pop (remove last)

Time: $\O(1)$

Space: May trigger shrinking

🔄 Insert at position

Time: $\O(n)$

Why: Shift elements + possible resize

🗑️ Delete at position

Time: $\O(n)$

Why: Shift elements left

// C++ Dynamic Array (vector) std::vector<int> vec; vec.push_back(10); // O(1) amortized vec.push_back(25); // O(1) amortized vec.insert(1, 15); // O(n) - insert at position 1 vec.erase(0); // O(n) - remove at position 0

⚡ Time & Space Complexity Analysis

📊 Time Complexity Summary

Operation Static Array Dynamic Array
Access O(1) O(1)
Search O(n) O(n)
Insert End N/A O(1)*
Insert Middle O(n) O(n)
Delete O(n) O(n)

*Amortized complexity

💾 Space Complexity

  • Static Array: O(n) - exactly n elements
  • Dynamic Array: O(n) - typically 1.5n to 2n capacity
  • Memory Overhead: Dynamic arrays have extra metadata
  • Cache Performance: Both excellent due to contiguous memory

🎯 Amortized Analysis Example

Dynamic array growth with doubling strategy:

Insertions: 1, 2, 3, 4, 5, 6, 7, 8, 9... Capacities: 1, 2, 4, 4, 8, 8, 8, 8, 16... Copies: 0, 1, 2, 0, 4, 0, 0, 0, 8... Total copies for n insertions ≤ 2n Therefore: Amortized O(1) per insertion
