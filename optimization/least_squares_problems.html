🎯 Lý Thuyết Cơ Bản

📐 Định Nghĩa Bài Toán

Mục tiêu: Tìm x để minimize ||Ax - b||₂²

Ý nghĩa: Tìm nghiệm "tốt nhất" cho hệ phương trình có thể không có nghiệm chính xác

minimize f(x) = ½||Ax - b||₂² = ½∑ᵢ(aᵢᵀx - bᵢ)²

⚡ Nghiệm Giải Tích

Normal Equation: AᵀAx = Aᵀb

Nghiệm: x* = (AᵀA)⁻¹Aᵀb (nếu AᵀA khả nghịch)

x* = A⁺b
A⁺ = (AᵀA)⁻¹Aᵀ (Moore-Penrose pseudoinverse)

💾 Examples

⚡ Normal Equation

Formula: x = (AᵀA)⁻¹Aᵀb

Ưu điểm: Exact, one-step solution

Nhược điểm: O(n³), unstable khi AᵀA ill-conditioned

Sử dụng: Small to medium problems (n < 10,000)

🔧 SVD Decomposition

Formula: A = UΣVᵀ, x = VΣ⁺Uᵀb

Ưu điểm: Numerically stable, handles rank deficiency

Nhược điểm: More expensive O(mn²)

Sử dụng: When A is ill-conditioned or rank deficient

🎯 QR Factorization

Formula: A = QR, Rx = Qᵀb

Ưu điểm: Good balance of speed and stability

Nhược điểm: O(mn²) cost

Sử dụng: General purpose, most common choice

🚀 Iterative Methods

Examples: Gradient Descent, CG, LSQR

Ưu điểm: Handle very large problems, O(n²) per iteration

Nhược điểm: Approximate, convergence issues

Sử dụng: Large-scale problems (n > 100,000)

🔬 Mathematical Deep Dive

📐 Geometric Interpretation

Orthogonal Projection: x* projects b onto column space of A

Residual: r = b - Ax* ⊥ Col(A)

||b - Ax*||₂ = min ||b - Ax||₂
x∈Rⁿ

⚡ Computational Aspects

Condition Number: κ(A) = σₘₐₓ/σₘᵢₙ

Numerical Stability: Use SVD when κ(A) > 10¹²

Error ≈ κ(A) × machine precision
≈ κ(A) × 10⁻¹⁶

🎯 Regularization Theory

Ridge Regression: minimize ||Ax - b||₂² + λ||x||₂²

Solution: x = (AᵀA + λI)⁻¹Aᵀb

Bias-Variance Tradeoff:
↑λ → ↑Bias, ↓Variance

📊 Statistical Properties

Unbiased Estimator: E[x*] = x (if noise ~ N(0,σ²I))

Covariance: Cov(x*) = σ²(AᵀA)⁻¹

R² = 1 - SS_res/SS_tot
0 ≤ R² ≤ 1
