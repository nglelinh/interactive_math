Backtracking Line Search

Kỹ thuật chọn độ dài bước thích ứng trong Gradient Descent

1. Vấn đề cốt lõi

Tại sao cần Backtracking Line Search?

Trong gradient descent cơ bản, chúng ta sử dụng learning rate cố định:

$$x_{k+1} = x_k - \alpha \nabla f(x_k)$$

Vấn đề: Chọn $\alpha$ như thế nào?

  • 🐌 $\alpha$ quá nhỏ: Hội tụ chậm, mất nhiều thời gian
  • 🚀 $\alpha$ quá lớn: Dao động, phân kỳ, không ổn định
  • 🎯 $\alpha$ tối ưu: Thay đổi theo từng bước và vị trí!

Ví dụ minh họa

Hãy tưởng tượng bạn đang xuống núi trong sương mù:

  • Sườn dốc: Có thể bước lớn an toàn
  • Gần vách đá: Phải bước nhỏ cẩn thận
  • Đường hẹp: Cần điều chỉnh từng bước

Backtracking Line Search như một "cảm biến thông minh" giúp chọn kích thước bước phù hợp!

Armijo Condition - Điều kiện chấp nhận bước

Nguyên lý Armijo

Một bước được chấp nhận nếu nó đảm bảo giảm đầy đủ hàm mục tiêu:

$$f(x_k - \alpha \nabla f(x_k)) \leq f(x_k) - c_1 \alpha \|\nabla f(x_k)\|^2$$

Các tham số:

  • $c_1 \in (0, 1)$: Hằng số Armijo (thường $c_1 = 10^{-4}$)
  • Vế trái: Giá trị thực tế sau bước nhảy
  • Vế phải: Giá trị mong đợi (giảm tuyến tính)

2. Thuật toán Backtracking

Thuật toán chi tiết

Khởi tạo:

  • $\alpha_0 > 0$: Learning rate ban đầu (ví dụ: 1.0)
  • $c_1 \in (0, 1)$: Hằng số Armijo (ví dụ: $10^{-4}$)
  • $\rho \in (0, 1)$: Hệ số thu nhỏ (ví dụ: 0.5)

Tại mỗi iteration:

  1. Bước 1: Tính gradient $g_k = \nabla f(x_k)$
  2. Bước 2: Khởi tạo $\alpha = \alpha_0$
  3. Bước 3: Lặp cho đến khi thỏa mãn Armijo:
    • Tính $x_{new} = x_k - \alpha g_k$
    • Nếu $f(x_{new}) \leq f(x_k) - c_1 \alpha \|g_k\|^2$: CHẤP NHẬN
    • Ngược lại: $\alpha \leftarrow \rho \alpha$ và thử lại
  4. Bước 4: Cập nhật $x_{k+1} = x_k - \alpha g_k$

Ví dụ tính toán cụ thể

Minimizing $f(x) = x^2$, starting from $x_0 = 2$

Iteration 1:

  • $g_1 = f'(2) = 4$
  • $f(2) = 4$
  • Thử $\alpha = 1.0$: $x_{new} = 2 - 1.0 \times 4 = -2$
  • $f(-2) = 4$ không thỏa mãn $f(-2) \leq 4 - 0.0001 \times 1.0 \times 16 = 3.9984$
  • Thu nhỏ: $\alpha = 0.5$, $x_{new} = 2 - 0.5 \times 4 = 0$
  • $f(0) = 0 \leq 3.9992$ ✓ CHẤP NHẬN!

Ý nghĩa hình học

Giải thích trực quan

Armijo condition yêu cầu hàm số giảm ít nhất một lượng tỷ lệ với độ dốc:

  • Nếu gradient lớn: Kỳ vọng giảm nhiều
  • Nếu gradient nhỏ: Kỳ vọng giảm ít
  • $c_1$ nhỏ: Dễ chấp nhận, ít backtrack
  • $c_1$ lớn: Khắt khe hơn, nhiều backtrack hơn

3. Phân tích lý thuyết

Tính chất hội tụ

Định lý hội tụ

Với hàm khả vi liên tục và bị chặn dưới:

  • ✅ Backtracking line search luôn terminates trong số hữu hạn bước
  • ✅ Gradient descent với BLS hội tụ về điểm stagnant
  • ✅ Đối với hàm convex: hội tụ về global minimum
  • ✅ Tốc độ hội tụ: $O(1/k)$ cho hàm convex, tuyến tính cho strongly convex

Độ phức tạp tính toán

Mỗi iteration

Function evaluations: Trung bình 2-5 lần

Worst case: $O(\log(1/\alpha_{min}))$ evaluations

Overhead: Nhỏ so với việc tính gradient

Toàn bộ thuật toán

Function evaluations: Tăng factor 2-3x

Iterations: Thường giảm 2-10x

Total cost: Thường tốt hơn fixed step size

Ứng dụng thực tế

Backtracking line search được sử dụng rộng rãi trong:

  • Optimization packages: SciPy, MATLAB, CVX
  • Machine learning: Training neural networks, logistic regression
  • Computer graphics: Shape optimization, mesh deformation
  • Engineering: Structural design, control systems
  • Finance: Portfolio optimization, risk management

4. Biến thể và mở rộng

Strong Wolfe Conditions

Điều kiện Wolfe mạnh

Kết hợp Armijo với điều kiện curvature:

$$f(x_k + \alpha p_k) \leq f(x_k) + c_1 \alpha \nabla f(x_k)^T p_k$$ $$|\nabla f(x_k + \alpha p_k)^T p_k| \leq c_2 |\nabla f(x_k)^T p_k|$$

với $0 < c_1 < c_2 < 1$ và $p_k$ là hướng tìm kiếm.

Zoom Line Search

Sử dụng interpolation để tìm step size tốt hơn

Ưu điểm
  • Ít function evaluations
  • Step size tốt hơn
Nhược điểm
  • Phức tạp hơn
  • Tính toán nặng hơn

Adaptive Backtracking

Điều chỉnh $\alpha_0$ dựa trên lịch sử

Ưu điểm
  • Học từ các bước trước
  • Hiệu quả hơn
Nhược điểm
  • Thêm tham số
  • Logic phức tạp

Fixed Step Size vs Backtracking vs Advanced Methods

Fixed Step Size

α cố định trong suốt quá trình

Ưu điểm
  • Đơn giản, dễ implement
  • Chi phí tính toán thấp
  • Không cần function evaluation thêm
Nhược điểm
  • Khó chọn α phù hợp
  • Không thích ứng với địa hình
  • Có thể hội tụ chậm hoặc phân kỳ

Backtracking Line Search

Tự động điều chỉnh α mỗi bước

Ưu điểm
  • Thích ứng với địa hình
  • Đảm bảo sufficient decrease
  • Robust, ít thất bại
  • Cân bằng tốc độ và ổn định
Nhược điểm
  • Thêm function evaluations
  • Phức tạp hơn về code
  • Có thể chậm khi backtrack nhiều

Wolfe Line Search

Điều kiện Armijo + Curvature

Ưu điểm
  • Step size chất lượng cao
  • Lý thuyết hội tụ mạnh
  • Hiệu quả với quasi-Newton
Nhược điểm
  • Phức tạp nhất
  • Nhiều function evaluations
  • Cần tính gradient thêm

Adaptive Methods (Adam, RMSprop)

Learning rate per-parameter

Ưu điểm
  • Hiệu quả với high-dim problems
  • Ít hyperparameter tuning
  • Phổ biến trong deep learning
Nhược điểm
  • Có thể không hội tụ đúng
  • Memory overhead
  • Hyperparameter sensitivity
