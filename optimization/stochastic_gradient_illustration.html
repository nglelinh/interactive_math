📊 Batch Gradient Descent

Update: x_{k+1} = x_k - α∇f(x_k)
Gradient: ∇f(x) = (1/N)Σ∇f_i(x)
  • Sử dụng toàn bộ dữ liệu
  • Gradient chính xác
  • Chậm với dữ liệu lớn
  • Hội tụ ổn định

🎲 Stochastic Gradient Descent

Update: x_{k+1} = x_k - α∇f_i(x_k)
Gradient: ∇f_i(x) (một mẫu ngẫu nhiên)
  • Sử dụng một mẫu ngẫu nhiên
  • Gradient nhiễu
  • Nhanh với dữ liệu lớn
  • Có thể thoát local minima
Mini-batch Gradient Descent:
Update: x_{k+1} = x_k - α(1/B)Σ∇f_i(x_k)
Batch size: B (1 < B < N)
Learning Rate Scheduling:
Constant: α_k = α_0
Decay: α_k = α_0/(1 + βk)
Adaptive: α_k = α_0/√(Σg_i²)
