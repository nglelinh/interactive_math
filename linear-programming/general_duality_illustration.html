📚 Thông tin Chi tiết

📊 Primal Problem

Minimize: f₀(x)
Subject to:
• fᵢ(x) ≤ 0
• hⱼ(x) = 0
  • Objective function: f₀(x)
  • Inequality constraints: fᵢ(x) ≤ 0
  • Equality constraints: hⱼ(x) = 0
  • Feasible region: intersection of constraints

🎯 Dual Problem

Maximize: g(λ, ν)
Subject to:
• λ ≥ 0
  • Dual function: g(λ, ν) = inf_x L(x, λ, ν)
  • Lagrangian: L(x, λ, ν) = f₀(x) + Σλᵢfᵢ(x) + Σνⱼhⱼ(x)
  • Always convex
  • Provides lower bounds
Weak Duality: g(λ, ν) ≤ f₀(x) for any feasible x, λ ≥ 0
Strong Duality: max g(λ, ν) = min f₀(x) (under Slater's condition)
Complementary Slackness: λᵢ*fᵢ(x*) = 0 for all i
Slater's Condition:
There exists x such that fᵢ(x) < 0 for all i and hⱼ(x) = 0 for all j
KKT Conditions:
∇f₀(x*) + Σλᵢ*∇fᵢ(x*) + Σνⱼ*∇hⱼ(x*) = 0, λᵢ* ≥ 0, λᵢ*fᵢ(x*) = 0
