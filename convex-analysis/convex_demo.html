📚 Lịch Sử Convex Analysis

📐 Hermann Minkowski (1864-1909)

Geometry of Numbers: Minkowski đặt nền móng cho hình học lồi (convex geometry) khi nghiên cứu về lý thuyết số và tương đối của Einstein.

🔬 Johan Jensen (1859-1925)

Jensen's Inequality (1906): Phát triển bất đẳng thức Jensen - công cụ cơ bản cho lý thuyết hàm lồi và theory thông tin.

⚡ Phát triển hiện đại

  • 1940s-1950s: Fenchel, Moreau phát triển convex conjugate và subdifferential
  • 1970s: Rockafellar viết "Convex Analysis" - sách giáo khoa kinh điển
  • Machine Learning boom: Convex optimization trở thành nền tảng của SVM, logistic regression

🌟 Tác động hiện đại

Từ nghiên cứu lý thuyết số, convex analysis đã trở thành nền tảng cho machine learning, portfolio optimization, và signal processing hiện đại.

📐 Understanding Convex Functions

🎯 Key Property: Any local minimum is a global minimum - this makes optimization much easier!

🔍 Function Analysis

📐 Mathematical Definition:

Convex Function: f(x) is convex if for any x₁, x₂ and λ ∈ [0,1]:

f(λx₁ + (1-λ)x₂) ≤ λf(x₁) + (1-λ)f(x₂)

Second Derivative Test: If f''(x) ≥ 0 for all x, then f(x) is convex.

🔍 Mathematical Properties

📈 Quadratic Functions

Form: f(x) = ax² + bx + c

Convex when: a > 0

Example: Linear regression uses MSE = ½∑(y - ŷ)²

📊 Exponential Functions

Form: f(x) = eˣ

Property: Always convex (f''(x) > 0)

Growth: Convex functions grow at least linearly

📐 Absolute Value

Form: f(x) = |x|

Property: Convex but not differentiable at x = 0

Example: Used in robust statistics (L1 norm)

🔄 Non-Convex Functions

Examples: sin(x), x³, oscillating functions

Problem: Multiple local minima

Challenge: Optimization can get stuck
